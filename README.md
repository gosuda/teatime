# hubconn

Standalone T-HUB Connector for Windows, Linux and macOS (amd64/arm64).

[Download the latest Connector release](https://github.com/gosuda/teatime/releases/latest). Releases contain six hubconn binaries, Connector installers and SHA256SUMS, with GitHub build provenance.

Install gjl separately from [its official website](https://gjl.io/). This repository does not redistribute gjl or the operator Hub executable.

This checkout contains only the Connector build sources and its local gjl IPC adapter. Organization configuration, Hub website/server sources, runtime state and private credentials are excluded.
